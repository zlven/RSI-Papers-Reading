# 论文笔记：JEPA-Anything 与 RSI-Anything

> 同一团队（PhAI Labs 联合港科大、上海 AI Lab、北大、港中大等）的两篇系列工作：
> - **JEPA-Anything**（arXiv:2609.20800，2026-09-17）解决"**如何跨域构建世界模型**"——提供预测底座；
> - **RSI-Anything**（arXiv:2610.13912，2026-10-09）解决"**如何用世界模型驱动递归自我改进**"——在底座上闭环。
> 两者构成"预测基础 + 改进机制"的上下层关系。

---

## 〇、分类定位

| 维度 | JEPA-Anything | RSI-Anything |
|---|---|---|
| 大类 | 世界模型（World Model）/ 自监督表示学习 | 递归自我改进（RSI）/ Agentic 自我演化系统 |
| 方法谱系 | JEPA 系（LeCun 的 Joint-Embedding Predictive Architecture，隐空间预测而非像素重建）→ OPF 正交预测分解扩展 | 世界模型 + 自改进 Agent 的交叉：继承 World Models / MuZero / Dreamer 的预测-规划思想，嫁接 Darwin Gödel Machine、Voyager、STaR 式的"保留经验证的改进"机制 |
| 贡献粒度 | 架构/学习原则（一个跨域共享的预测核心） | 系统协议（更新—触发—门控—保留的操作规范） |
| 关键词 | 隐空间预测、正交分解、跨域世界模型、科学发现 | 递归自我改进、策略—模型配对、可靠性触发、兼容性门控 |

## 一、JEPA-Anything: Learning Predictive Models across Different Worlds

### 1. 动机
- 现有预测模型都是领域专用的：视觉一套、分子动力学一套、临床轨迹又一套。
- 核心提问：**是否存在一个共同的预测学习原则，能支撑差异巨大系统上的世界建模？**
- 标准 JEPA 的短板：所有可预测信息被塞进单一预测器/单一目标嵌入，容易的模式会淹没难的模式（多种预测模态混在一个整体目标嵌入里）。

### 2. 核心 Insight
- 把预测目标**分解为互补因子**：不是学一个整体预测，而是学 K 个正交子空间上的分预测，再合成为完整隐状态。
- 因子的身份（identity）不预定义语义，**从预测学习本身涌现**。
- 领域无关性体现在"原则共享、接口分离"：各域保留自己的观测、token化、编码器和读出头，只共享**因子化预测核心**——接入新域只需写观测适配器。

### 3. 方法：正交预测分解（OPF）
1. 学 K 个可训练投影器 P_k ∈ R^{d×r}，取 Kr = d，把 stop-gradient 的目标表示分解为 K 个子空间因子：z_t^{(k)} = P_k^T · sg(z_t)；
2. 每个因子有专属预测器 q_k，从共享上下文表示 z_c（+目标描述符 s_t，+外生输入 ξ_t 如动作/干预）预测对应子空间 ẑ_t^{(k)}；
3. 拼接后用 Moore–Penrose 伪逆合成完整隐状态：ẑ_t = (P^T)† û_t；P 严格正交时退化为简单求和 Σ P_k ẑ_t^{(k)}；
4. 训练目标 = 因子预测回归（直接回归每个因子到目标，保持方向与幅度）+ 正交性正则（因子间不重复编码相同方向，精神上类似 Barlow Twins/VICReg 的去冗余）+ 因子活性与编码器方差正则；作为加性损失叠加在各域原有 JEPA 基损失上；
5. 合成都态是统一接口：可解码未来状态、做多步 latent rollout、供规划器打分（OPF 提供预测状态，应用提供奖励定义）。

### 4. 实验设计（七域三评测组）
- **域覆盖**：视觉、生物、临床轨迹、控制、分子动力学、物理场、天气。
- **评测组 I（终端读出）**：受控视觉绑定、单细胞状态表示；
- **评测组 II（隐空间世界动力学）**：Interventional Pong 干预条件预测、运动任务因子干预、10 个匹配动力学任务；
- **评测组 III（科学分析）**：湿实验干预提名、轨道标度律恢复。
- **关键结果**：全部 10 个动力学任务上超过匹配 JEPA 基线；Interventional Pong 单次干预预测误差降 34.8%；四个分子体系的一步与 100 步 rollout 误差均最低；>1000 临床事件预测；潜因子恢复的轨道标度指数斜率 -1.4991（理论值 -1.5，开普勒第三律）；模型提名的生物干预组合（IL-18 + CD73 阻断）在细胞共培养、患者来源类器官、肿瘤碎片、小鼠中获得实验支持。

### 5. 意义与边界
- 把 JEPA 从视觉/视频推向科学领域，暗示"单一预测原则跨域可行"，且**隐因子可作为科学分析接口**（可解释、可检验），超越黑箱预测。
- 边界：不是单一通用编码器/统一权重，而是统一接口；不模拟一切科学环境（未与 ScienceBuddy/ScienceIDE 打通）。

## 二、RSI-Anything: Unlocking Recursive Self-Improvement with World Models

### 1. 动机
递归自我改进（RSI）要把交互经验转化为**持久的**能力提升（上一轮的改进被保留并塑造下一轮）。两个瓶颈：
1. **真实反馈昂贵**：跑测试、做湿实验、GUI 操作都有真实成本，"先执行后学习"在有限预算下探索效率极低；
2. **策略—世界模型耦合漂移（coupled-update challenge）**：策略更新改变候选分布 → 旧世界模型在新分布上失真；世界模型更新改变候选排序与学习信号。**单独改进任一方不保证联合系统变好**；策略与模拟器无约束自博弈会崩溃（模型脱离现实、策略钻漏洞 reward hacking）。

### 2. 核心 Insight
- **改进单元从"策略"提升为"策略—世界模型配对"**：持久改进应定义在系统级，演化策略下的预测可靠性是核心设计约束；
- **经验双重利用**：执行后得到的"预测—观测"配对既评估候选效用，也审计预测器可靠性；
- **门控优于盲目吸收**：世界模型适配由可靠性检查触发，更新保留由组件+兼容性检查决定，保证版本受控演进。

### 3. 方法：六阶段循环（Propose → Predict → Select → Evaluate → Learn → Retain）
- **形式化**：领域 d 定义任务元组 𝒯_d = (观测𝒳, 状态𝒮, 动作𝒜, 适配器𝒲, 验证器𝒱, 指标, 约束, 预算ℬ)；系统状态为配对 (θ_k, ϕ_{d,k})，k 计更新周期（不等于成功修订次数）。
- **预测引导选择**：策略提候选 → 世界模型做动作条件隐状态预测 ẑ_{t+1}=F(z_t,a_t) → readout 转效用分 R_d = Σw_j r_j − Δ（Δ 为可选不确定性惩罚）→ 只把排名最高的候选送去真实执行；可选多步 rollout（需适配器提供规划状态传播）。
- **证据分级**：E0 规则检查 / E1 学习模型预测 / E2 高保真模拟器 / E3 外部真实测量；"想象轨迹"进训练集由独立准入标准（有效性、效用阈值、不确定性上限）门控。
- **反馈驱动双路更新**：
  - 策略/工作流更新（θ）：demonstration / 偏好学习 / 工作流搜索，视领域而定；
  - 条件式世界模型适配（ϕ）：可靠性评估三档 {reliable, unreliable, insufficient}，**仅判定 unreliable 且数据充足、预算够时才触发**；覆盖不足=证据不足而非可靠，不触发更新；可靠性评估要求预测归属当前模型版本。
- **递归保留机制**：两层门控——组件检查（G^π_k / G^W_k，新组件是否优于当前）→ 兼容性检查（G^pair_k，在匹配评估条件下比较整个候选配对与当前配对，防止"新策略的候选恰好落在新模型失准区"）；任一层失败即回退；被保留的配对塑造下一轮候选分布与经验，闭合递归环。
- **异步演化**：策略与世界模型可按各自节奏更新。

### 4. 实验设计（五域，各验证不同组件）
| 领域 | 验证点 | 关键结果 |
|---|---|---|
| 代码修复（CodeContests 200 题×3 种子；另测 APPS / LiveCodeBench v6） | coder 固定（ReasonFlux-Coder-7B），4 候选选 1；对比随机/静态验证器/固定世界模型（CURE-WM-Lite）/自适应世界模型 | 26.3%（静态验证器）→ 29.2%（预测引导选择）→ **31.2%**（再适配）；排序准确率 66.5%→72.8%，Brier 0.488→0.358；在线测试调用量几乎不变（≈3.72 次/题） |
| GUI（MiniWoB++ click-checkboxes + OSWorld） | 策略与世界模型**同时**更新 | 成功率 51%→79%→**99%**；每回合动作数降 39.4%（5.30→3.21），重复点击 237→0；OSWorld 相对初始 agent +18.4%，比 RLAnything 再高 5.5% |
| 湿实验规划（LabHorizon F200） | 同一自我改进过程中**连续 5 代 4B 策略** | Level-2 得分 21.80→38.03→41.99→44.56→**46.01%**（五代翻倍），超过 Qwen3.6-35B Actor + Gemini 3.1 Pro 模拟器/选择器参考系统（45.32%） |
| 化学反应优化（两个 Suzuki–Miyaura 筛选） | 与贝叶斯优化在**匹配实验次数**下对比 | GC 屏 20 次实验：93.0% vs 87.5%；LC–MS 屏 40 次：平均最佳产率 **96.15% vs 82.16%**（+13.99 pp） |
| 免疫科学端到端 | 串联：工作流演化→免疫世界模型→带自我纠错分析→前瞻性治疗假设 | 框架贯通性演示 |

严谨性设计：代码实验 coder 固定、候选预算相同；化学实验次数匹配；update 数据与 gate 数据分离，held-out audit set 用于最终报告。

### 5. 意义
- 贡献不是更强的策略或世界模型，而是让两者在**反馈稀缺 + 分布漂移**下安全协同进化的**门控递归协议**：世界模型省下昂贵反馈，稀疏真实反馈锚定世界模型，兼容性检查保证每次保留都是净改进。
- 代码与模型均已开源（github.com/Gen-Verse/RSI-Anything）。

## 三、两篇的关系与相关工作脉络

```
JEPA（LeCun, 2022）→ I-JEPA / V-JEPA / V-JEPA 2 → JEPA-Anything（OPF，七域预测底座）
                                                            ↓ 作为预测基础
World Models(1990s)/MuZero/Dreamer/Genie  ──────────→  RSI-Anything（预测 + 递归保留）
                                                            ↑ 对照与差异
STaR / DPO / Reflexion（反馈→学习） ；Voyager（技能积累）；
Darwin Gödel Machine（保留经验证的 agent 修改）；
RLAnything（策略+奖励+环境联合优化，OSWorld baseline）；
Actor–Simulator–Selector（LabHorizon 参考系统）
```

- **继承**：世界模型的预测-规划思想（Ha & Schmidhuber、MuZero、Dreamer）；JEPA 隐空间预测范式；CURE（代码实验的 coder 与 CURE-WM-Lite 来自它）；DGM 式"保留经验证的系统修改"。
- **对照点**：RLAnything 联合优化策略/奖励模型/环境，RSI-Anything 在其之上 OSWorld +5.5%，差别在于 RSI-Anything 强调**异步更新 + 可靠性触发 + 配对兼容性门控**，把"何时更新、更新后是否保留"变成显式受控决策。
- **推进方向**：对 Recuris、ScienceBuddy 等长程 RSI 工作的延伸——显式把预测式世界模型放进递归环；免疫科学端到端演示预示 AI-for-Science 闭环发现方向。

## 四、一句话记忆

- **JEPA-Anything** = "把世界状态正交分解成互补因子分别预测再合成"——一个跨七域共享的**预测学习原则**；
- **RSI-Anything** = "策略与世界模型作为配对，在门控递归协议下协同进化"——一套反馈稀缺下安全的**自我改进操作规范**。
