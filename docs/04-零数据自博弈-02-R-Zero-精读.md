## 1. 研究背景与动机

论文瞄准的瓶颈是：自进化 LLM 训练仍依赖人工准备的任务与标签。Absolute Zero 证明了零数据可行，但依赖代码执行器这一硬验证环境。R-Zero 的动机是把零数据自进化推广到**没有执行器的领域**：用模型自身的统计信号（自一致性）同时充当难度计与答案来源，实现完全不依赖任何外部验证设施的闭环。论文将自身定位为"从单一基座从零生成全部训练数据的全自主框架"。

## 2. 核心 Insight 与理论依据

**核心 insight**：模型对一道题的**多次采样答案分布**包含两种免费信号——
- **难度信号**：答案分歧越大（自一致性越低），题目越处于模型能力边缘；峰值约在 50% 成功率处；
- **伪标签信号**：多数投票的众数答案，在没有真值时充当近似标签。

由此，Challenger 被奖励去出"分歧最大"的题，Solver 被训练去解这些题并用众数自证——整个循环无需任何外部判据。

**理论依据**：自一致性（self-consistency）作为不确定性度量的既有传统；多数投票作为弱监督伪标签的传统；GRPO 作为训练算法。论文没有新的形式理论，其贡献在系统设计：把这两种统计信号接成一个**共进化回路**（Challenger 校准难度 → 数据生成 → Solver 变强 → Challenger 重新校准），并论证这构成一个"靶向自改进课程"。

## 3. 方法详解

### 3.1 流程（每轮）

1. **Challenger 训练**（Solver 冻结）：用 GRPO 训练 Challenger 生成难题；奖励来自冻结 Solver 对每题多次采样的**不确定性**（按自一致性度量，奖励在约 50% 成功率处最大）；
2. **数据构造**：对合成题目用过滤策略 + 多数投票机制生成 (question, pseudo-label) 对；
3. **Solver 训练**（Challenger 冻结）：Solver 在该数据集上以 GRPO 微调，伪标签充当验证信号；
4. 迭代。两个模型独立持有权重、交替优化。

### 3.2 可修改范围与 RSI 分级

| 可修改对象 | 是否被修改 | 修改者 |
|---|---|---|
| Challenger 权重 | ✅ | GRPO（不确定性奖励） |
| Solver 权重 | ✅ | GRPO（伪标签验证） |
| 任务分布/课程 | ✅ Challenger 逐轮生成 | Challenger |
| 判据（自一致性+众数） | ❌ 固定统计规则 | —— |
| 训练算法 | ❌ | —— |

**分级：L1.5**。课程自产权移交模型（Challenger），且两角色权重独立进化——比共享权重的双角色设定更彻底地"角色分化"。但判据与算法仍固定。

## 4. 实验设计

- **基座**：Qwen3-4B-Base、Qwen3-8B-Base 等多个 backbone（验证方法跨基座有效性）。
- **任务**：数学推理基准组 + 通用推理基准组（后者检验非数学域的泛化）。
- **Baseline**：基座模型；与其他零数据/自生成方法对比（论文在相关工作与实验中定位自身）。
- **关键分析（论文亮点之一）**：**题目难度与标签准确率的演化**——跟踪各代 Solver 在当代 Challenger 题目上的成功率（对角线），以及伪标签相对真值的准确率随迭代的变化。

## 5. 评估三问

### Q1：内部判据

**统计式判据，无外部锚**。难度判据 = 自一致性（Solver 答案分布的分散度）；答案判据 = 多数投票众数。这套判据的优势是完全摆脱执行器/真值依赖，适用面远宽于 AZR；代价是**判据与模型的系统性错误同源**——如果 Solver 一致地犯同一个错，多数投票会把错误答案固化为标签。论文的诚实之处是把这一侵蚀过程**量化展示**了（见 §6），而非回避。

### Q2：外部审计

held-out 基准（数学组 + 通用组）在多个基座上复测。外部设计合格但有缺口：迭代轮数较少（3 轮量级）；标签侵蚀与外部分数之间的定量关系（"标签烂到什么程度时外部分数开始掉"）未建立。

### Q3：量化方式

逐轮基准分 + **对角线成功率表**（第 k 代 Solver 对第 k 代题目约 50%——证明 Challenger 精确履行了难度校准职责）+ 伪标签准确率演化。这套"内部机制指标 + 外部能力指标"的双层量化比单报 benchmark 分信息量更大。

## 6. 实验结果与分析

- **Qwen3-4B-Base**：数学推理组 +6.49，通用推理组 +7.54；更大基座同样提升；
- **课程校准验证**：对角线成功率——Solver (Iter 2) 对当代题目 51.5%、Solver (Iter 3) 50.5%——奖励函数设计的目标（约 50% 成功率）被精确实现；
- **标签侵蚀（论文自报的负面发现）**：随着迭代推进，题目变难，多数投票伪标签的绝对准确率**下降**——Solver 在变强的同时，其伪标签在更难的题上变得更不可靠；
- **共进化动态**：两模型交替冻结训练避免了单模型双角色的目标干扰。

**分析**：R-Zero 的结果把零数据自进化的核心张力摆上了台面——**判据强度与域覆盖的交换**：放弃执行器换来了任意领域，代价是判据退化为统计众数，而众数判据在难题上系统性地贬值。论文用对角线表证明了"难度校准"设计成功，也用标签准确率曲线记录了这一设计的内在代价。

## 7. 结论与意义

R-Zero 证明零数据自进化不必须依赖执行器——双模型分裂 + 统计信号足以撑起一个共进化循环，并在数学与通用推理上都产生实质收益。它对谱系的贡献有两层：①把"零数据"从可验证域推广到一般域；②用诚实的标签侵蚀分析为后续工作立下了最重要的研究问题：**没有硬判据的自举循环如何对抗标签漂移**。

## 8. 未来方向（论文自身展望）

论文指出：缓解标签准确率侵蚀（如外部知识接地、更强的伪标签机制）；更长迭代下的稳定性；向更多任务域推广。

## 9. 批判性问题清单

1. **众数即真值的系统性风险**：多数投票在模型存在系统性偏误时会固化错误——这在小基座 + 难题的组合上尤其危险，论文的侵蚀曲线已经给出了预警。
2. **迭代深度不足**：3 轮左右的实验无法回答"长期自举是否崩溃"——而标签侵蚀趋势暗示答案可能不乐观。
3. **不确定性奖励的可被钻空性**：Challenger 可通过出**语义含糊/病态题**制造答案分歧（分歧≠有教育意义的难度）；论文的过滤策略能否挡住这类 adversarial 出题未被压力测试。
4. **双模型的成本**：两份独立权重的存储与交替训练开销相对单模型方案翻倍，性价比未核算。
5. **50% 成功率目标的理论依据**：为何最优课程在 50% 而非其他水平？论文以奖励设计实现之，但未论证其最优性。
