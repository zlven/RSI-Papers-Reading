## 1. 动机

- LLM Agent 做 ML 工程的主流是线性试错；人类数据科学家的工作方式是**系统探索解空间**（分支、回退、复用）。能否把后者形式化？

## 2. Insight 与方法

- **树搜索形式化**：草案 → 调试 → 树搜索式迭代改进；节点级代码保持简洁，每次 LLM 调用只处理局部问题（如只调试最有希望的脚本）；
- 24 小时时间窗内持续复用/改进分支而非重启。

## 3. 关键结果

- MLE-bench：o1-preview+AIDE 奖牌率 16.9%（约次优 OpenHands 的 4 倍）；
- 脚手架消融：MLE-bench Lite 上有效提交率 63.6%→92.4%、超人类中位数比例 13.6%→59.1%（p<0.01）；
- RE-Bench：6 小时内超人类基线；Optimize-a-Kernel 任务发现的 Triton 方案快过 9 位人类专家 64 小时的所有方案。

## 4. 评估三问
