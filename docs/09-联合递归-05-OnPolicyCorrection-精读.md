## 1. 动机（漏斗）

1. **领域现状**：自动 harness 进化能让小模型在企业任务上以远低于前沿模型的成本表现良好；直观下一步是用强专家监督缩小剩余差距。
2. **现有痛点**：无——这正是论文要打破的"直观"。
3. **核心矛盾**：harness 与权重共同塑造行为，但**harness 是围绕特定模型的行为风格进化出来的**；用风格迥异的专家轨迹训练会破坏这种协同适应。
4. **本文目标**：识别并解决 harness 更新与权重更新之间的一种contention 来源。
5. **切入角度**：模仿学习的负迁移文献 + on-policy 学习原则。
6. **核心 idea**：不模仿专家的完整轨迹，而是在弱模型**自己的** rollout 中定位失败轮次、只让专家重写那一轮——保留模型的规划风格。

**判断**：动机独特且重要——这是联合优化文献中罕见的"先证明直觉错了"的论文。

## 2. Insight 与理论依据

- **核心 insight**：**model-harness fit** 是真实存在且脆弱的资产。机制分解：模仿确实转移了知识、确实增加了 scaffold 使用率，但弱模型"采纳了专家的规划策略却没有执行它的能力"，且不再匹配围绕其原生规划风格进化的 harness。三个观察（知识↑、scaffold 使用↑、总分↓）合在一起排除了"模仿没用"的浅层解释。
- **理论依据**：on-policy vs off-policy 学习的经典区分；行为克隆的分布偏移（compounding error）理论是隐含支撑。
- **严格使用还是隐喻借用**：on-policy 原则是严格使用；fit 概念是操作性定义（通过破坏实验间接测量）。
- **逻辑跳跃**：从七任务负结果到一般性"compatibility-preserving recipe"的外推宽度未证。

## 3. 方法（摘要级重构）

### 3.1 实验骨架

1. 用弱模型进化 harness（冻结权重）；
2. 观察：强专家在此 harness 下表现更好 → 引出"专家监督可缩小差距"的假设；
3. **证伪**：专家完整轨迹 → 模仿训练弱模型 → 七任务全回退（-4~-30pp，Qwen3-Coder 与 Gemma 4）；同一程序在未进化 harness 下有帮助——对照点关键，证明回退归因于 harness 的进化状态而非模仿本身；
4. **机制分析**：知识转移↑、scaffold 使用↑、但规划风格错配；
5. **修复**：meta-level MLE agent 自动化的 on-policy 纠错管线——定位弱模型自己 rollout 的失败轮次，专家只重写该轮。

### 3.2 关键设计（三段式）

> **未进化 harness 下的模仿对照**
> - 功能：把回退归因到"进化状态"而非"模仿"
> - 核心思路：同一模仿程序 × 两种 harness 状态
> - 设计动机：没有这个对照，负结果可以被解释为"专家监督本来就不好"

> **轮次级专家纠错（on-policy correction）**
> - 功能：获得专家知识而不替换模型的规划风格
> - 核心思路：只在模型自己的轨迹上改失败轮次——训练信号停留在模型自身的分布上
> - 设计动机：直接应用 on-policy 原则；与 STaR/ReST 的区别是监督源是专家而非自举，与完整模仿的区别是局部而非全局

> **MLE agent 自动化**
> - 功能：把纠错管线本身自动化（元层级）
> - 核心思路：meta-level agent 定位失败轮次并发起纠错
> - 设计动机：减少人工参与；但 MLE agent 的可靠性成为新的未检验环节

### 3.3–3.4 RSI 专项

- 可修改范围：harness（进化）+ 权重（纠错微调）；改进器（进化算子、MLE agent）固定。
- 分级：L1+ 级联合管线。与本文系列的相关性不在递归性，而在**它测量了 L5 双循环中一个隐蔽的失效模式**：权重相位如果用的是 off-policy 监督，会破坏 harness 相位积累的 fit——这直接约束 Co-Harness 式"轨迹 SFT 内化"的有效性条件。

## 4. 实验（摘要级）

- 基准：七个企业 agent 任务；模型：Qwen3-Coder、Gemma 4。
- 主数字：模仿回退 -4~-30pp（全七任务、两模型家族）；管线修复后"结合了 harness 进化与模型适应的增益"。
- 缺口（未见全文）：逐任务数字、纠错轮次定位的准确率、专家成本、与 on-policy RL（如 GRPO）的直接对比。

## 5. 评估三问

- **Q1 内部判据**：任务成功率（企业任务 verifier）；纠错轮次的定位判据未见。
- **Q2 外部审计**：双模型家族 + 未进化 harness 对照是强点；未见跨任务 held-out。
- **Q3 量化方式**：回退幅度逐任务报告；机制分解（知识/使用/分数三分离）是本簇最细的行为归因之一。

## 6–7. 结论与缺点

- 站得住：负结果本身（有对照、双家族、全任务一致方向）；fit 破坏的机制叙事（三分离证据）。
- **额外缺点**：fit 只有破坏性操作（模仿）下的间接测量，无正向度量指标；纠错管线引入专家成本，未与"直接 on-policy RL"比较——若弱模型 on-policy 自举就够，专家必要性存疑；企业任务的保密性可能阻碍复现。
- **最可能被攻击的点**：专家纠错 vs 纯 on-policy RL 的消融缺失；fit 概念的操作化不足。

## 8. 谱系定位

- **前置**：harness 进化线（Meta-Harness/Self-Harness）；模仿学习与 on-policy 文献。
- **定位一句话**：联合优化簇的"fit 守恒定律"第一次实证——harness 进化积累的协同适应是会被粗暴权重更新破坏的资产，权重相位的监督必须与模型自身分布对齐。
- vs 对比：**vs Co-Harness**：Co-Harness 的 SFT 内化用模型自己验证过的轨迹（天然 on-policy），本文从反面证明了为什么要这样做；**vs Harness-Zero**：蒸馏派试图部署时去掉 harness，本文表明这种去除在 fit 视角下天然危险；**vs Ceiling 论文**：Ceiling 回答"训什么"，本文回答"用什么分布训"——两个互补的内化约束。

| 维度 | 本文 | Co-Harness | Harness-Zero（蒸馏） |
|---|---|---|---|
| 权重监督来源 | 专家轮次纠错（on-policy） | 自产验证轨迹 SFT | 优化 harness 行为蒸馏 |
| 与模型分布对齐 | 是（设计目标） | 是（自产） | 否（harness 介导） |
| fit 处理 | 显式保护 | 隐式满足 | 部署时移除 harness |
| 核心证据 | 负结果+机制分解 | 两轮增益 | 未见全文 |

## 9. 批判性问题清单（供组会讨论）

1. （方法）MLE agent 定位失败轮次的准确率是多少？误定位（改了不该改的轮次）对 fit 的影响是否被测量？
2. （实验）缺少"纯 on-policy RL（无专家）"基线——专家监督的增量价值在控制分布对齐后还剩多少？
3. （概念）fit 能否正向测量（而非仅通过破坏推断）？例如用 harness 参数扰动下模型性能的敏感度作为 fit 指标？
4. （实验）回退幅度 -4~-30pp 的方差很大——什么任务/模型特征预测回退严重性？有无预测性规律而非事后解释？
5. （外推）若 harness 持续进化而权重持续纠错，两者的长期共同演化是否收敛？fit 是需要每次重建的成本还是可积累的资产？
