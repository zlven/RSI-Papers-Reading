## 1. 背景与动机

**定位**：2026 年 6 月，AI 自我改进从哲学讨论进入实验室运营数据。本文是**首个以前沿实验室内部测量为基础的 RSI 进展报告**，作者为 Anthropic 联合创始人 Jack Clark 与 Anthropic Institute 的 Marina Favaro。

**动机**：把"RSI 还有多远"的辩论从推测转向测量；并提前为治理争取时间。

## 2. 核心数据点（转述来源一致的部分）

1. **代码占比**：2025-02 Claude Code 发布前，AI 编写代码占个位数百分比；至 **2026-05，>80%** 的合并代码由 Claude 编写；
2. **工程师吞吐**：人均日合并代码量 2021–2024 持平，至 2026-Q2 达 **2024 年的 8×**（报告自注：行数是不完美度量，8× 几乎必然高估真实生产率增益）；
3. **任务时长曲线**（引 METR）：AI 可可靠完成的任务时长约**每 4 个月翻番**（此前为 7 个月）——2024-03 Claude Opus 3 ≈ 4 分钟人类任务；2025 Claude Sonnet 3.7 ≈ 1.5 小时；2026 Claude Opus 4.6 ≈ **12 小时**；
4. **优化任务的超人点**：2026-04，Claude Mythos Preview 在小模型训练代码优化任务上达 **~52× 加速**（熟练人类研究员通常 4–8 小时做到 4×）——一年内从"很有帮助"到"超越人类"；
5. **研究循环**：一个研究循环在一周内闭合了某基准差距的 **97%**（对照：两名人类研究员同期闭合 23%）（第三方转述）；
6. **基准饱和**：SWE-bench 两年内从个位数到饱和；CORE-Bench（研究复现）从 2024 初约 20% 到 15 个月后饱和。

## 3. 核心论证结构

1. **测量即论证**：加速不是预测而是记账；
2. **但这不是 RSI**（报告的关键克制）：RSI 的严格定义——AI **自主主导继任者开发的完整周期**（从架构到实现）——尚未满足；人类仍设定研究方向、做关键判断；
3. **"比多数机构准备好的更快"**：即使严格 RSI 未至，当前斜率已迫使治理提前；
4. **政策主张**：国际协调的减速/暂停机制（"刹车踏板"）——当安全研究跟不上时，前沿实验室应有能力放慢。

## 4. 评估三问视角

- **Q1**：报告不涉及内部判据（非技术方法文）；
- **Q2**：其数据本身是"外部审计 RSI 进展"的稀缺一手材料——但注意**全部数据自报、无第三方审计**；
- **Q3**：8× 的自注（行数高估生产率）展示了罕见的测量诚实；但 80% 的"编写占比"未区分"生成"与"净贡献"。

## 5. 影响与反响

- 与 OpenAI 九月的"An Alien Mind"（"研究实习生"里程碑：每人类工作日 3.1 个智能体工作日；2028-03 目标全自动研究员）共同设定了 2026 下半年"实验室意义"的 RSI 议程；
- 被学术综述（2607.07663）引用为"前沿实验室闭环叙事"的代表，并提示：**此类工业实践在任何 arXiv 语料中系统性缺席**；
- 治理侧：进入美国州立法听证材料与 AIWS 等治理讨论文件；
- 批评：一边加速一边呼吁刹车的动机张力被广泛讨论。

## 6. 批判性问题清单

1. **自报数据的审计缺位**：80%/8×/52× 均无独立验证；
2. **指标选择的叙事效应**：行数/任务时长是"加速友好"指标；研究品味、方向设定等"人类仍在环"的维度无量化；
3. **刹车踏板倡议的利益冲突**：规则制定者同时是竞赛领先者；
4. **与学术定义的张力**：报告用"AI 研发占比"叙事，而学术界（两篇同期综述）坚持"改进决策权"才是 RSI 判据——两种话语的错位本身就是 2026 年的领域特征。
