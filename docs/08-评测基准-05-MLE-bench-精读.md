# MLE-bench 精读报告

> 按 RSI 论文精读模板 v1.0 生成

## 0. 论文元信息

- **标题**：MLE-bench: Evaluating Machine Learning Agents on Machine Learning Engineering
- **作者**：OpenAI
- **发表**：ICLR 2025；arXiv:2410.07095（2024-10）
- **一句话总结**：75 个 Kaggle 竞赛端到端 ML 工程评测，按 Kaggle 奖牌制评级。
- **速读结论**：对象层"AI 研发能力"最广泛引用的代理基准；外部锚定（Kaggle 排行榜）抗腐蚀；读结果必须先问脚手架。推荐。

## 1. 方向与领域 → 动机

- **核心问题**：Agent 能否端到端完成 ML 工程（数据准备→建模→调优→提交）？
- **动机**：为"AI 自动化 AI 研发"提供可追踪进度条；Kaggle 奖牌天然带人类分布参照。

## 2. Insight 与理论依据

- **外部锚定抗腐蚀**：评分来自真实竞赛排行榜而非自建测试——评测者无法被刷分（但随时间污染风险上升）；
- **奖牌制**：把连续表现映射到人类竞赛者分布的分位数语义。

## 3. 方法

- 75 个竞赛，覆盖多种模态与任务类型；Agent 在容器内端到端执行；按 Kaggle 规则评奖牌（铜/银/金）。

### 【RSI 专项】判级

- 对象层能力代理，回路不在评测内；**RSI 谱系中的角色**：AIDE² 的 held-out 基准之一（MLE-Bench Lite）、OpenAI Preparedness 的"AI 自我改进"类目组件。

## 4. 实验设计与关键结果

- 基线：o1-preview + AIDE 脚手架 **16.9% 铜牌率**（pass@8 升至 34.1%）；
- 脚手架消融：MLE-bench Lite 上加 AIDE 使 o1-preview 有效提交率 63.6%→92.4%、超人类中位数比例 13.6%→59.1%（p<0.01）——**脚手架贡献可翻三倍**；
- 后续：AIRA-dojo 用 MCTS 把奖牌率推到 47.7%。

## 5. 评估三问

- **Q2 外部审计**：强（真实排行榜）但防污染靠任务保密/滚动；**Q3 量化**：奖牌率（偏序语义）。

## 6. Contribution

确立"Kaggle 奖牌率"作为 ML 工程能力的通用货币；暴露脚手架混淆问题。

## 7. 缺点

- Kaggle 任务≠改进 AI 系统；污染随时间上升；金牌语义随竞赛热度漂移。

## 8. 定位

对象层三足鼎立之一（与 RE-Bench/PaperBench）；AIDE 谱系的常驻试炼场。
