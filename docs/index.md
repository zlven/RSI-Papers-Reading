## 评估三问（本系列的核心分析框架）

每篇精读的第 5 节固定回答三个问题：

- **Q1（内部判据）**：系统自己如何判断一次修改"成立"？——门控式 / 选择式 / 契约式 / 协议强制 / 执行反馈 / 学习评判器 / 内在自评 / 环境锚定 / 统计众数 / 外部神谕 / 无判据……
- **Q2（外部审计）**：旁观者如何判断这个 RSI 系统"真的在改进"？——held-out 基准、固定预算、独立实现、人类审计、真实同行评审……
- **Q3（量化方式）**：改动如何被量化？——标量适应度、偏序支配、通过率差、成本帕累托、复合指标……

## RSI 分级图例（本系列约定）

| 分级 | 含义 | 代表 |
|---|---|---|
| **L0** | 一阶改进：改进器固定，改进对象是外部产物 | FunSearch、AlphaEvolve、ADAS |
| **L0.5** | 边界形态：推理时自我修正 / teacher 外置循环 / 一次性结构搜索 | Self-Refine、LLM2LLM、AFlow |
| **L1** | 自举循环：模型产出变成训练信号反过来改变模型，改进算子固定 | STaR、ReST-EM、SPIN |
| **L1- / L1+** | L1 变体：记忆/上下文级持久化（-）；判据参与共进化（+） | Reflexion、Voyager、ACE（-）；Self-Rewarding（+） |
| **L1.5** | 课程自产：连"学什么"都由系统内生 | Absolute Zero、R-Zero、SPICE |
| **L2** | 改进者可被替换/改写，但改进规则固定 | SICA、Self-Harness、AIDE² |
| **L3** | 完全自指：改写逻辑自身也在可改写范围内 | Gödel Agent、HSI、MetaSkill-Evolve、HyperAgents |
| **L4 / L5** | 评估器可改写（L4+）；权重×脚手架联合递归（L5）；理论上限（L5+） | RQGM；Co-Harness；Gödel Machine |

> 上表是本系列自用的分级约定，用于横向定位；文献自带的坐标系（如 D2I 的 L1–L5）另按各自定义阅读，见对应笔记。

1. **先立框架**：`02-综述-01`（验证层级）→ `01-主线-01`（Gödel Machine 理论锚点）
