## 1. 动机（漏斗）

1. **领域现状**：科研 agent 以一次性部署为主（AI Scientist 系），与研究者日常协作脱节；harness 改进与模型训练两条线各自孤立。
2. **现有痛点**：(1) 科研 agent 不随使用变强；(2) 研究者的交互证据（请求、反馈、执行结果）被浪费，未转化为训练信号。
3. **核心矛盾**：持续改进需要持续的真实任务分布与评估信号——只有嵌入日常工作流才能获得；而嵌入工作流又要求 agent 已经足够好用。
4. **本文目标**：构建一个把"被研究者使用"本身转化为自我改进燃料的科研 agent 系统。
5. **切入角度**：产品化——以 research product 形态发布，让真实交互数据飞轮转起来。
6. **核心 idea**：recursive-in-recursive——harness 演化塑造训练经验，模型学习又创造 harness 适应的新机会。

**判断**：动机成立且方向重要（人机协作作为 RSI 的持续判据来源，是对"判据从哪来"问题的一个产品化解法）；但摘要层面的证据完全无法支撑有效性结论。

## 2. Insight 与理论依据

- **核心 insight**：研究者交互是免费、持续、与真实科研分布对齐的评估信号源——把它形式化为任务与 rubrics，就同时解决了 L5 联合递归的"数据从哪来"与"判据从哪来"。
- **理论依据**：无；范式性工作。
- **严格使用还是隐喻借用**：recursive-in-recursive 是结构性描述（双环耦合），非形式化概念。
- **逻辑跳跃**：从"交互证据可用"到"双环递归有效"的全部因果链都依赖未报告的实验。

## 3. 方法（摘要级，细节原文未获取）

### 3.1 系统骨架

1. 研究者在工作空间中执行科研任务（四个任务族）；
2. 内环：模型冻结，系统根据交互证据改进 harness；
3. 外环：在改进的 harness 下用交互转化的任务/rubrics 做模型强化学习；
4. 两环相互塑造：harness 演化定义训练经验分布，模型更新创造 harness 适应的新空间。

### 3.2 关键设计

- **交互证据→训练资产的转化管线**（请求/反馈/执行证据 → 任务 + 评估 rubrics）——全文最具体的机制，但转化规则、rubrics 质量门控、防污染措施均未见。
- **产品化发布**本身作为方法的一部分（真实分布的获取手段）。

### 3.3 【RSI 专项】可修改范围

- ☑ harness（内环）　☑ 模型权重（外环 RL）
- ☐ 双环结构自身　☐ rubric 生成机制（未见说明）
- 载体：未详。

### 3.4 【RSI 专项】RSI 实现程度

**判级：L5-雏形（结构层面）**。双环耦合在结构上符合"权重×脚手架联合递归"；但"递归"的深度证据（外环跑了几轮？是否有第 3 轮以后的收益？）在摘要级材料中完全缺失。判级保留待全文核实。

## 6. Contribution 与结论

- 自陈贡献：recursive-in-recursive 范式；ScienceBuddy 系统发布；四任务族案例。
- **我的判断**：范式命名与产品化落地成立（社区引用已在使用该术语）；有效性声称不成立（无证据）。"向发现智能体迈进一步"是愿景陈述而非结论。

## 7. 缺点与攻击面

- **额外缺点**：
  1. 无基准、无数字、无对照——三无量化；
  2. 人机协作环引入的评估偏置未讨论（研究者会回避使用难任务/失败任务吗？交互证据的选择效应）；
  3. rubrics 由系统自产——判据内生但没有 RQGM 式的锚定或对抗机制；
  4. 双环的稳定性（振荡/相互过拟合）无任何分析——对照 WHALE 的调度研究，这正是已知的失效区。
- **最可能被攻击的点**：有效性证据缺失；交互数据的自选择偏置。

## 8. 谱系定位

- **前置**：Co-Harness（双循环的先驱，有数字）；WHALE（调度科学）；AI Scientist 系（科研 agent 形态）。
- **定位一句话**：把 L5 从"离线双循环"推向"在线人机协作双循环"的范式提案——方向成立，证据缺席。
- vs 对比：
  - **vs Co-Harness**：相同点=双环耦合；关键差异=Co-Harness 离线自主运行 200+ 小时有数字，ScienceBuddy 在线人机协作无数字；
  - **vs WHALE**：WHALE 回答"双环怎么调度"，ScienceBuddy 假设"双环该嵌入工作流"——问题互补，证据强度悬殊。
