## 0. 论文元信息

- **标题**：PostTrainBench: Can LLM Agents Automate LLM Post-Training?
- **作者**：Rank 等
- **发表**：ICML 2026；arXiv:2603.08640（2026-03）
- **一句话总结**：给 Agent 一个基座模型、一块 H100、十小时，看它自主找到多强的后训练策略。
- **速读结论**：权重级 RSI 的最小闭环实测；固定算力/时间预算天然满足 matched-budget；2026 年 10 月已出现递归自进化 Agent 登顶（AIBuildAI），是当前最活跃的回路层竞技场。推荐。

## 1. 方向与领域 → 动机

- **子领域**：回路层评测（权重级自我改进）。
- **核心研究问题**：LLM Agent 能否自主完成后训练研究（选方法、写训练代码、跑实验、迭代），达到或超过人工后训练配方？
- **动机**："模型改进模型"此前没有可复现的公开实测；PostTrainBench 把它压缩成单实验。

## 2. Insight 与理论依据

- **固定资源、放开策略**：单卡 H100 + 10 小时是硬约束，策略空间完全开放——把"谁更聪明"从"谁资源多"中分离；
- **盲评**：checkpoint 在 Agent 不可见的评测集上打分，防止 Agent 针对评测优化。

## 3. 方法

- 4 个基座模型 × 7 个目标基准（AIME 2025、GSM8K、GPQA、HumanEval、BFCL、Arena-Hard、HealthBench）；
- Agent 可自由使用后训练技术全家桶（SFT/RL/数据合成/课程设计），产出最终 checkpoint；
- 主指标：盲评集上的性能提升。

### 【RSI 专项】可修改范围与判级

- ☑ 训练数据/配方/代码　☐ 评测集　☐ 算力预算
- **判级：L3**（固定改进机制内的自主改进闭环；与 RSIBench-Data 同层但 Target 是整个后训练策略而非仅数据）。

## 4. 实验设计与结果

- 初始结论：Agent 能完成有意义的后训练改进，但与最佳人工配方有差距；长程信用分配（哪一步改动带来最终提升）是主要失效点；
- **后续动态（2026-10）**：AIBuildAI 的"递归自进化 PostTrain Agent"登顶排行榜——改进 PostTrain Agent 本身的元回路开始在该基准上竞争，基准正在从"测 Agent"演化为"测改进 Agent 的回路"。

## 5. 【RSI 专项】评估三问

- **Q1 内部判据**：Agent 自选（通常是小规模验证集）；**Q2 外部审计**：强（盲评 + 固定预算）；**Q3 量化**：盲评集原生分数。

## 6. Contribution 与结论

权重级自我改进从"论文声明"变成"可复现竞赛"；算力门槛低（单卡），是入门 RSI 实证的最佳入口。

## 7. 未来方向与缺点

- 单次改进，无代际维度；10 小时预算偏向"快糙猛"策略；基座模型随时间更新导致跨期比较困难。
