## 1. 研究背景与动机

**领域位置**：RSI 谱系中"**反馈稀缺 + 分布漂移**"这一现实约束下的工程化解法。此前的主线工作（DGM、SICA、HGM、Live-SWE-agent）多在**单一领域（软件工程）**内、以**基准通过率为唯一外部信号**驱动自我改进；RSI-Anything 的问题设定不同：它要求同一套自我改进协议**跨领域成立**，而各领域的真实反馈代价差异极大。

**核心问题**：如何在没有廉价真实反馈的条件下，让系统持续产生**被保留下来的**能力提升？

论文识别出两个瓶颈：

1. **真实反馈昂贵**：跑测试套件、做湿实验、在 GUI 上试错都有真实成本。"先执行后学习"在有限预算下探索效率极低——大量算力被浪费在注定失败的候选上。
2. **策略—世界模型耦合漂移（coupled-update challenge）**：这是本文最核心的观察。策略更新 → 候选分布改变 → 旧世界模型在新分布上失真；世界模型更新 → 候选排序与学习信号改变。**单独改进任一方都不保证联合系统变好**。更尖锐的是：策略与模拟器无约束自博弈会崩溃——模型脱离现实（预测越来越不准）、策略钻漏洞（reward hacking）。

**痛点**：既有的"世界模型 + 规划"工作（Dreamer、MuZero 系）默认策略是**被训练**的、环境是**给定**的；而 RSI 场景下策略与环境模型**都在变**，且变动的判据本身需要被治理。

## 2. 核心 Insight 与理论依据

### 2.1 关键洞察

1. **改进单元从"策略"提升为"策略—世界模型配对"**。持久改进应当定义在**系统级**：单纯让策略变强不是改进，让"策略 + 它据以决策的世界模型"这一配对整体变强才是。由此，**演化策略下的预测可靠性**成为核心设计约束，而非事后检查项。
2. **经验双重利用**。执行后得到的"**预测—观测**"配对同时服务两个目的：评估候选的真实效用（更新策略），以及**审计预测器本身的可靠性**（决定是否更新世界模型）。同一份稀缺真实反馈被榨取两次，这是方法论上最经济的一点。
3. **门控优于盲目吸收**。世界模型的适配由**可靠性检查触发**（而非每轮无条件更新），配对的保留由**组件检查 + 兼容性检查**共同决定——保证版本受控演进，每一步都"可回退、可归因"。
4. **预测只用于排序，不用于替代真实评估**。世界模型的作用是**把有限的真实执行预算花在排名最高的候选上**，最终接受与否仍由真实反馈裁决——这从结构上堵住了"模型自说自话"的路径。

### 2.2 理论依据与方法论谱系

- **无形式理论**。本文不提供收敛性或最优性证明，其主张是**协议级**的工程论证：何种更新顺序与门控组合能让配对在漂移下受控演化。这与 Gödel Machine 的"可证明有益才自改"形成两极——RSI-Anything 用**经验门控**取代**形式证明**。
- **谱系**：世界模型的预测-规划思想（Ha & Schmidhuber 1990s、MuZero、Dreamer）提供"用预测代替试错"的机制；JEPA 系（LeCun）的隐空间预测范式提供表示与预测接口；DGM 式"**只保留经验证的修改**"提供递归保留的骨架。本文的贡献是把三者缝合成一套**跨域操作规范**。
- **预测底座（背景）**：JEPA-Anything 提出**正交预测分解（OPF）**——把隐空间预测目标分解为 K 个正交子空间上的分预测，各配专属预测器，再以 Moore–Penrose 伪逆（或严格正交时的简单求和）合成为完整隐状态；因子语义从预测学习中涌现，各域只共享因子化预测核心、保留自己的观测与编码器。其在视觉、生物、临床轨迹、控制、分子动力学、物理场、天气**七域**上验证，并给出隐因子可作科学分析接口（潜因子恢复的轨道标度指数斜率 −1.4991，理论值 −1.5）。RSI-Anything 直接复用这一底座作为 φ 的架构与初始化。

### 2.3 与已有工作的联系（论文自述）

- **vs RLAnything**（联合优化策略 / 奖励模型 / 环境）：同为"多方共进"，RSI-Anything 在其之上 OSWorld 再高 5.5%；差异在于本文强调**异步更新 + 可靠性触发 + 配对兼容性门控**——把"何时更新、更新后是否保留"从隐式副作用变成**显式受控决策**。
- **vs Actor–Simulator–Selector**（LabHorizon 参考系统）：本文在湿实验规划上以 4B 策略超过 Qwen3.6-35B Actor + Gemini 3.1 Pro 模拟器/选择器的组合（46.01% vs 45.32%）。
- **vs DGM / 保留式自我改进**：继承"保留经验证的系统修改"，但把保留判据从**单组件性能**改成**配对级兼容性**。

## 3. 方法详解

### 3.1 形式化设定

- 领域 d 定义任务元组 𝒯_d = (观测 𝒳, 状态 𝒮, 动作 𝒜, 适配器 𝒲, 验证器 𝒱, 指标, 约束, 预算 ℬ)；
- 系统状态为**配对 (θ_k, φ_{d,k})**：θ 为策略/工作流，φ 为世界模型，k 计**更新周期**（注意 k 不等于成功修订次数——被门控拒绝的轮次也计入 k）；
- 目标：在预算 ℬ 下最大化跨域指标，且保证每次保留都是净改进。

### 3.2 六阶段循环（Propose → Predict → Select → Evaluate → Learn → Retain）

| 阶段 | 做什么 | 关键设计 |
|---|---|---|
| **Propose** | 策略提出候选动作 / 工作流 / 方案 | 候选分布由上一轮保留的配对塑造——递归环的入口 |
| **Predict** | 世界模型做动作条件隐状态预测 ẑ_{t+1} = F(z_t, a_t) | 可选多步 latent rollout（需适配器提供规划状态传播） |
| **Select** | readout 转效用分 R_d = Σ w_j r_j − Δ（Δ 为可选不确定性惩罚），**只把排名最高的候选送去真实执行** | 真实反馈预算的守门人 |
| **Evaluate** | 对入选候选执行真实评估，得到"预测—观测"配对 | 证据分级见 3.3 |
| **Learn** | 双路更新：策略/工作流 θ（demonstration / 偏好学习 / 工作流搜索，视领域而定）；条件式世界模型适配 φ | φ 的更新是**条件式**的，见 3.4 |
| **Retain** | 两层门控决定新配对是否替换当前配对 | 见 3.5 |

**异步演化**：策略与世界模型可按各自节奏更新，不必同步。

### 3.3 证据分级（E0–E3）

| 级别 | 证据类型 | 说明 |
|---|---|---|
| **E0** | 规则检查 | 语法/约束的确定性校验 |
| **E1** | 学习模型预测 | 世界模型给出的隐空间预测 |
| **E2** | 高保真模拟器 | 领域模拟器 |
| **E3** | 外部真实测量 | 跑测试、做湿实验、真实 GUI 交互 |

"**想象轨迹**"（纯预测、未经真实校验的 rollout）进入训练集需通过**独立准入标准**：有效性、效用阈值、不确定性上限三者同时满足才可入集——这是防止"模型自产自销"造成坍缩的具体闸门。

### 3.4 条件式世界模型适配（本方法的关键约束）

可靠性评估给出三档判定 {reliable, unreliable, insufficient}：

- **仅当判定为 unreliable、且数据充足、且预算允许时**，才触发世界模型适配；
- **覆盖不足（insufficient）不等价于可靠**——证据不足时不触发更新（防止"没见过就当成对"）；
- 可靠性评估要求**预测归属当前模型版本**（避免用旧版本的战绩给新版本背书）。

### 3.5 递归保留机制：两层门控

1. **组件检查**（G^π_k / G^W_k）：新策略组件、新世界模型组件是否各自优于当前？
2. **兼容性检查**（G^pair_k）：在**匹配的评估条件**下比较**整个候选配对**与当前配对。

第二层是本文最有辨识度的设计：它专门防止"**新策略的候选恰好落在新模型失准区**"这一类单组件检查看不见的失效。任一层失败即**回退**；被保留的配对塑造下一轮的候选分布与经验，**闭合递归环**。

### 3.6 可修改范围（RSI 视角）

| 层级 | 触及？ | 说明 |
|---|---|---|
| 策略 / 工作流 θ | ✅ | 主改进对象（demonstration / 偏好学习 / 工作流搜索） |
| 世界模型 φ | ✅ | **条件式**适配（可靠性触发）——充当候选筛选器，故触及评估器层 |
| 候选生成与筛选机制 | ✅ | 由 (θ, φ) 的连续演化间接改变 |
| 六阶段循环协议 | ❌ | 人类预置，固定 |
| 可靠性三档判据 / 门控规则 | ❌ | 人类预置，固定（这是判据的**治理边界**） |
| 权重（底层 LLM） | ❌ | 本文实验中 coder 等骨干固定（代码域明确"coder 固定"） |

### 3.7 RSI 实现程度

- **递归深度**：**两层可改对象 + 一层固定协议**。改进对象不是单点而是配对，且配对的第二个成员（世界模型）恰是**上一轮的判据来源**——这构成了实质性的自指张力：**判据本身在变**。
- **分级判定**：**L4-**。理由：φ 承担"候选效用排序"的评估器角色且可被自适应改写，满足"评估器可改写"的 L4 判据方向；但改写**协议**与**门控规则**固定，且适配是被可靠性检查有条件地触发而非自由进化，强度明显弱于 RQGM 的 L4+（评估器 U 与策略、模型同列进化空间）。因此记为 L4 的下界形态。
- **与 L2 的界线**：若只把世界模型视为"训练好的工具"而非判据的一环，本工作会落在 L2；本文判为 L4- 的关键理由，是论文自己把**可靠性评估**写成了适配的触发条件——即系统对"自己的判据何时可信"有显式建模，这正是评估器进入自指范围的标志。

## 4. 实验设计

### 4.1 五域设置（每个领域验证不同组件）

| 领域 | 验证点 | 设置 |
|---|---|---|
| **代码修复** | 预测引导选择 + 条件适配的**分步增益** | CodeContests 200 题 × 3 种子（另测 APPS / LiveCodeBench v6）；coder 固定为 ReasonFlux-Coder-7B；4 候选选 1；对照组：随机选择 / 静态验证器 / 固定世界模型（CURE-WM-Lite）/ 自适应世界模型 |
| **GUI** | 策略与世界模型**同时**更新 | MiniWoB++ click-checkboxes + OSWorld |
| **湿实验规划** | 同一自我改进过程中的**连续多代**演化 | LabHorizon F200 |
| **化学反应优化** | 与贝叶斯优化在**匹配实验次数**下对比 | 两个 Suzuki–Miyaura 筛选（GC 屏 20 次；LC–MS 屏 40 次） |
| **免疫科学** | 端到端框架贯通性 | 工作流演化 → 免疫世界模型 → 带自我纠错的分析 → 前瞻性治疗假设 |

### 4.2 严谨性设计

- 代码实验：**coder 固定**、候选预算相同（隔离"是模型变强还是流程变好"）；
- 化学实验：与贝叶斯优化**实验次数严格匹配**（这一点是该领域公平比较的常见陷阱）；
- **update 数据与 gate 数据分离**，最终报告另用 **held-out audit set**；
- 消融按"静态验证器 → 预测引导选择 → 再加适配"**逐步加码**，使每一层的净贡献可见。

## 5. 评估和测评依据（评估三问）

### Q1 内部判据：系统自己如何判断一次修改"成立"？

- **主判据为环境锚定 + 门控式**：候选的最终接受由**真实反馈**（E3：测试通过、湿实验结果、真实 GUI 交互）裁决，世界模型只负责排序；
- **判据自身被分层治理**：预测证据按 E0–E3 分级，E1（学习模型预测）只有在满足有效性/效用/不确定性三项准入后才可进入训练集；
- **保留判据是配对级的**：G^pair_k 在匹配条件下比较整个配对——判据不只看"新组件是否更强"，还看"新组合是否整体更优"；
- **判据的可信度被显式建模**：可靠性三档 + "预测须归属当前模型版本"，使系统对"何时不该相信自己的预测器"有明确回答。
- **脆弱点（论文自认）**：世界模型的可靠性判定本身依赖真实反馈样本，在**反馈极端稀缺**的领域（近 E3 样本接近零）该判定会落入 insufficient 而不触发更新——即**世界模型无法自我纠正**，递归在此停滞。

### Q2 外部审计：旁观者如何判断它"真的在改进"？

- **固定预算对照**：化学域与贝叶斯优化在**同实验次数**下比较（96.15% vs 82.16%），排除了"靠更多试验刷分"；
- **固定 coder**：代码域锁定被改进的底层模型，使增益只能归因于协议而非更强底座；
- **held-out audit set**：最终指标在未参与 update 与 gate 的数据上报告；
- **多代持续性**：湿实验规划报告**连续五代**的分数轨迹（21.80→38.03→41.99→44.56→46.01），而非单次最优——"持久改进"这一主张需要轨迹而非端点来支撑，此处设计到位；
- **与参考系统的对标**：湿实验域直接对比 Actor–Simulator–Selector 参考系统，代码域对比 CURE-WM-Lite，给出的是同任务同预算下的可比数字。

### Q3 量化方式：改动如何被量化？

- **主指标**为领域通过率 / 成功率 / 产率等标量；
- **辅助指标**含排序质量（排序准确率 66.5%→72.8%；Brier 0.488→0.358，用于度量世界模型预测校准）、成本（每回合动作数、每问题测试调用量）；
- **改进被分解为可归因的三段**：静态验证器 → 预测引导选择 → 再加适配。这种"逐层加码"的量化方式使"世界模型到底贡献了多少"成为可回答的问题，优于只报告最终数字；
- 未采用成本帕累托或偏序支配形式。

**评估三问总评**：本文在 **Q3 上最突出**——把"预测引导"与"条件适配"的增益拆开报告（26.3→29.2→31.2），并同时给出排序质量与校准指标，使世界模型的价值可被独立审计而不仅是端到端背书。**Q2 扎实**：固定预算、固定 coder、update/gate/audit 三方数据分离、连续五代轨迹，四项都是该系列里较严格的做法。**Q1 是本文最有野心也最脆弱的一环**：它让判据（世界模型）进入可改写范围，同时用可靠性门控与配对兼容性检查加以约束——方向正确，但可靠性判据本身的样本需求与递归停滞风险论文未予量化。

## 6. 实验结果与分析

### 6.1 代码修复：预测的价值可被分解

| 配置 | 成功率 |
|---|---|
| 静态验证器 | 26.3% |
| + 预测引导选择 | 29.2% |
| + 世界模型条件适配 | **31.2%** |

- **排序准确率 66.5% → 72.8%**，**Brier 0.488 → 0.358**（预测校准显著改善）；
- **在线测试调用量几乎不变（≈3.72 次/题）**——这是关键：增益来自"**把同样的真实预算花在更好的候选上**"，而非花更多预算。世界模型在此扮演的是**预算杠杆**，不是替代品。

### 6.2 GUI：联合更新才有效

- 成功率 **51% → 79% → 99%**；
- 每回合动作数 **-39.4%**（5.30 → 3.21），重复点击 **237 → 0**；
- OSWorld 相对初始 agent **+18.4%**，比 RLAnything 再高 **5.5%**；
- 分析：这一域**策略与世界模型同时更新**，且重复点击归零说明学到的是"**别做无用动作**"这一环境结构，而非特定动作序列——符合"世界模型改善候选分布"的解释。

### 6.3 湿实验规划：多代持续性

- Level-2 得分：21.80 → 38.03 → 41.99 → 44.56 → **46.01%**（**连续五代翻倍**）；
- **超过** Qwen3.6-35B Actor + Gemini 3.1 Pro 模拟器/选择器参考系统（45.32%）——**4B 策略 + 自改进协议胜过 35B 策略 + 更强外部组件**。这是本文"协议 > 规模"主张最直接的一处证据。

### 6.4 化学反应优化：同预算胜过贝叶斯优化

| 筛选 | 实验次数 | RSI-Anything | 贝叶斯优化 |
|---|---|---|---|
| GC 屏 | 20 | **93.0%** | 87.5% |
| LC–MS 屏 | 40 | **96.15%** | 82.16%（+13.99 pp） |

- 贝叶斯优化是低预算实验设计的强基线，在同次数下被显著超过，说明世界模型提供的**动作条件预测**比纯统计代理模型携带了更多结构信息。

### 6.5 免疫科学端到端

- 串联"工作流演化 → 免疫世界模型 → 带自我纠错分析 → 前瞻性治疗假设"，作为框架**贯通性演示**（而非定量结论）。

## 7. 结论与意义

- **结论**：本文的贡献**不是更强的策略，也不是更强的世界模型**，而是让两者在**反馈稀缺 + 分布漂移**下安全协同进化的**门控递归协议**：世界模型省下昂贵反馈，稀疏的真实反馈锚定世界模型，兼容性检查保证每次保留都是净改进。
- **领域意义**：
  - 指出了一条**绕过"真实反馈瓶颈"**的 RSI 路径——在真实反馈昂贵到无法支撑"先执行后学习"的领域（湿实验、临床、化学），预测式世界模型可能是唯一可行的规模化途径；
  - 把"**改进单元 = 配对**"这一提法给了 RSI 谱系一个可操作的中间层：既不必改写改进协议（L3），也不止于改写单点工件（L2），而是在评估器层动手（L4 轴）；
  - **跨五域的单一协议**是本文相对多数单域自我改进工作的结构性差异——自我改进协议本身的可迁移性得到了检验。
- **局限**：
  - 无收敛性或最优性理论保证；"保留即净改进"依赖门控规则的正确性，而规则由人类设计且未做敏感性分析；
  - 可靠性判定需要真实反馈样本，反馈过少时系统会退化为"不更新"——本文未给出该退化发生的定量边界；
  - 五域实验各自的评估条件不完全一致（任务、预算、指标的尺度不同），跨域结论是**协议可用性**层面的，不能读作跨域性能可比；
  - GUI 99% 接近饱和，天花板效应可能掩盖协议在更难任务上的差异。

---

## 8. 未来方向（基于论文自述与结构性缺口）

1. **可靠性判据的样本效率**：如何用更少的真实反馈判断世界模型何时可信——这直接决定本框架能否用于反馈极稀缺的科学域；
2. **门控规则的自动化**：当前 G^π、G^W、G^pair 的判定规则与阈值由人类预置，将其纳入可进化范围即从 L4- 走向 L4+；
3. **更多领域的适配器工程**：接入新域只需写观测适配器（继承 JEPA-Anything 的"原则共享、接口分离"），但论文未报告非作者团队接入新域的成本；
4. **长程多轮联合评估**：第三方评论指出需要更多"策略与世界模型联合多轮演化"的评估，而非单轮对照。

## 9. 批判性问题清单（精读者视角）

1. **"配对保留"的判据会不会被套利？** G^pair_k 在"匹配评估条件"下比较配对——但评估条件本身由谁选定？若条件集合固定，长期演化可能同时过拟合策略与模型到该条件集合上，形成**配对级的基准过拟合**。论文未见条件集轮换或对抗性条件生成的讨论。
2. **世界模型的可靠性判定缺乏形式化**。三档 {reliable, unreliable, insufficient} 的分界阈值、以及"数据充足"的量化标准，在方法论层面是**人为设定的超参数**，却承担着"何时允许改判据"这一最敏感的决策。其敏感性未做消融。
3. **反馈稀缺时系统停滞**，而恰恰是反馈最稀缺的领域最需要 RSI。论文把世界模型作为省反馈手段，但**审计世界模型自身又需要真实反馈**——存在一个未被讨论的循环依赖，可能限制本方法在最需要的场景中的适用性。
4. **预测只用于排序的架构上限**。"只把排名最高的候选送去执行"在候选**质量分布重叠**时收益有限；当预测器无法区分候选（Brier 接近随机）时，协议退化为随机选择。论文给出了代码域 Brier 改善，但未报告**预测失效条件下**的退化曲线。
5. **4B 胜过 35B 的对照条件**。湿实验域中参考系统用的是"35B Actor + Gemini 3.1 Pro 模拟器/选择器"这一**外部拼接**的组合，而本文是端到端自改进——两者的比较是否真正同预算、同评估器？该结论的分量取决于这组对照的公平性细节。
6. **跨域"单一协议"的可信度**。五域验证的是同一协议的**可用性**，但每个领域都配置了领域专属的适配器、指标与门控阈值。举"跨域通用"时，被共享的究竟是协议骨架，还是只剩"有个循环"这一层？
7. **免疫科学端到端结果无定量结论**。该域作为"框架贯通性演示"出现，未报告可比的评测数字，在五域证据链中属于**承载叙述而非承载证据**的一环。
