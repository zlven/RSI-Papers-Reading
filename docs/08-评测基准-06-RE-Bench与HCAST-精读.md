# RE-Bench / HCAST / 时间地平线 精读报告

> 按 RSI 论文精读模板 v1.0 生成（METR 方法论三件套合并精读）

## 0. 论文元信息

- **标题**：RE-Bench（ICML 2025）；HCAST: Human-Calibrated Autonomy Software Tasks（arXiv:2503.17354）；Measuring AI Ability to Complete Long Tasks / Time Horizon 1.1（2025–2026）
- **作者**：METR
- **一句话总结**：7 个开放式 ML 研发任务 + 189 个人类校准任务 + 一套"50% 成功率交叉点"的时间地平线测量方法。
- **速读结论**：RSI 预测的宏观标尺与任务工程教科书；同时是"时间地平线≠独立工作时长"这一警示的原出处。必读（方法论部分）。

## 1. 方向与领域 → 动机

- **核心问题**：如何用一个标量概括"AI 能自主完成多长的人类工作"，并追踪其随时间的变化？
- **动机**：为 RSI"何时到来"提供可外推的趋势标尺；为政策与实验室安全框架提供触发器依据。

## 2. Insight 与理论依据

- **时间地平线**：先测人类专家完成任务的时长，再拟合 Agent 成功率随人类时长下降的 logistic 曲线，取 50% 交叉点；
- **人类基线对齐条件**：140 名专业人员在与 Agent **相同的环境设定**下完成 563 次尝试——不是事后估算；
- **任务工程**：HCAST 189 任务（143 内部 + 46 外部悬赏征集），多轮对抗性 QA（人+Agent 试跑找 bug 与非预期解法），仅公开 11 个任务族防污染。

## 3. 方法与关键结果

- RE-Bench：7 个任务（优化 kernel、修复训练等），连续分数 + 人类 8h 对照；Agent 在短任务已超人类，长任务仍有差距；
- Time Horizon 1.1（2026-01）：228 任务；长期翻倍周期约 7 个月，2023 年来加速至约 4.3 个月；Claude Opus 4.6 约 12h、Mythos Preview 约 17.4h（置信区间宽）；
- **自陈局限**：时间地平线 ≠ 独立工作时长（误差约 2×）；去掉非公开 RE-Bench 任务后 Opus 4.6 从 12h 掉到 7h（建模假设敏感）；任务分布偏软件工程。

## 4. 评估三问

- **Q2 外部审计**：方法公开、任务部分保密（审计-防污染张力）；**Q3 量化**：50% 交叉点标量 + 置信区间。

## 5. Contribution

- 提供了当前唯一被跨实验室引用的"自主性时间标尺"；HCAST 的任务工程流程（双轨征集/对抗 QA/保密管理）是自建基准的模板。

## 6. 缺点与批判性问题

1. 保密任务集削弱外部审计——社区只能信任 METR 内控；
2. 软件工程偏向下，向科研/数学/生物等领域的外推效度未知；
3. 若"对象层能力增长"与"回路层改进能力增长"不同步（见 RSIBench-Data 的非单调性），用时间地平线外推 RSI 时间表的方法论基础是否成立？

## 7. 定位

宏观趋势标尺（非基准）；与对象层基准互补：基准测"现在能不能"，时间地平线测"按趋势什么时候能"。
