# MLS-Bench 精读报告

> 按 RSI 论文精读模板 v1.0 生成

## 0. 论文元信息

- **标题**：MLS-Bench: A Holistic and Rigorous Assessment of ML Research Agents
- **作者**：Princeton / UW 等
- **发表**：2026；社区平台 mls-bench.com
- **一句话总结**：140 个任务 × 12 个 ML 研究领域，要求 Agent 改进**可泛化、可扩展的 ML 方法**而非局部调优。
- **速读结论**：把对象层测量从"执行已知方法"（PaperBench）推向"发明新方法"；核心发现"工程调优易、方法发明难"是评估 AI 研究能力时的重要分界。推荐。

## 1. 动机

- PaperBench 测复现（理解+执行），MLE-bench 测工程竞赛；都不测**方法发明**——提出一个跨设定、跨规模成立的新方法。
- 核心问题：Agent 能否做出可泛化的 ML 研究贡献？

## 2. Insight

- **泛化验证内置于任务**：改进必须在跨设定、跨规模下验证才算数，堵死"针对单设定过拟合"的捷径。

## 3. 方法与结果

- 140 任务 / 12 领域；要求提交方法级改进 + 跨设定验证；
- 核心发现：Agent 擅长工程式调参（超参、tricks 组合），拙于真正的方法发明；**更多搜索/算力/上下文不能消除这一瓶颈**——能力缺口是结构性的而非资源性的。

## 4. 评估三问

- **Q2 外部审计**：跨设定验证作为硬性要求（强）；**Q3 量化**：方法泛化性指标。

## 5. Contribution 与定位

- 在对象层基准中划出"执行↔发明"的分界线；对 RSI 的含义：若方法发明是瓶颈，则 RSI 回路的上限被"改进算子的创造力"而非"搜索算力"决定——支持 RSI-Bench"算子发现"轴的独立性。
